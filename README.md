An algorithm to auto identify title block, so to enable prevention of AI processing drawing with sensitive title block data.
The very first version was only to determine the title block, successfully achieving at date April 17th 2026.
Later version dated at April 18th 2026, it successfully determine the naming inside the title block with some pre-conditions set in it.
Further research study may utilize it to fine tuning more criteria in enhancing the identification and determination of drawing naming.
That would help to utilize algorithm in pre-processing drawing relevant data, preventing sensitive data being processed by AI model for reinforced learning and etc.
